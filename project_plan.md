# Project Plan — Generative Summarization & Insight Extraction
Author: Aayush Sharma
Start Date: 2025-11-15
Deadline: 2025-12-01

## Scope
- Abstractive summarization using BART/T5.
- Sentiment & emotion classification using RoBERTa/DeBERTa.
- Actionable insight extraction using SBERT embeddings + clustering.
- Build a simple dashboard (Streamlit/Flask).
- Produce final PDF report.

## Evaluation Metrics
### Summarization
- ROUGE-1, ROUGE-2, ROUGE-L
- BERTScore (optional)

### Sentiment & Emotion
- Precision, Recall, F1 (macro)
- Confusion matrix

### Insight Extraction
- Cluster precision & coverage
- Human-evaluated relevance

## Deliverables
- GitHub code repository
- Final PDF report
- Dashboard demo
- Data preparation and model training scripts
